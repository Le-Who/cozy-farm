Из семян откройте «Свои планы огорода» → «Семена для свободных грядок» → «Собрать список семян». Для свободных мест: 8 монет, для полного посева: 12 монет. Проверить отмену, покупку, повторный ввод, возврат, обычный посев и перезагрузку. Ферма создаётся только на порту 4268, существующие записи не перезаписываются.

Результат: семена, монеты, грядки, планы
