# Cozy Farm

Браузерная ферма на двух островах. Выращивайте овощи и фруктовые деревья, кормите кур, ловите рыбу и продавайте урожай. Выручка позволяет купить лодку и улучшить дом, курятник и колодец. В кухне из урожая, яиц, рыбы и морской соли можно приготовить блюда на продажу.

## Запуск

Нужен Node.js 22.18 или новее. Из папки `game` выполните:

```sh
npm ci
npm run dev
```

`npm test` проверяет правила фермы. `npm run build` собирает статические файлы в `dist`. `npm run preview` открывает локально собранную версию.

## Управление

- Нажмите на грядку, чтобы обработать землю, посадить выбранные семена, полить или собрать урожай. Подсказка над грядкой показывает следующее действие.
- Колодец пополняет лейку. В доме можно отдохнуть, приготовить блюда и купить улучшения. Курятник и рынок открывают свои меню.
- Погладьте курицу нажатием или перетащите её по загону. Забота о разных курах повышает настроение стаи и влияет на кладку.
- Нажмите на причал или выберите удочку. Забросьте леску и подсекайте, пока индикатор находится в зелёной зоне.
- Купите саженец на рынке и посадите его у деревянной метки. Дерево растёт на лужайке и снова плодоносит после сбора.
- Купите лодку у причала, чтобы попасть в Saltwind Grove. Там можно ловить морского окуня, собирать соль и разбить ещё один сад.
- С клавиатуры нажмите `Tab`, чтобы сфокусировать остров. Стрелки выбирают цель, `Enter` выполняет действие. `1`–`8` открывают инструменты и сумки, `J` открывает журнал, `?` — справку.
- На телефоне кнопка **Field view** увеличивает огород. **Island view** возвращает общий план.

Успешные действия автоматически сохраняются в текущем браузере. День продвигается по мере работы. Вечером можно продолжать работать столько, сколько нужно, а новый день начинается после отдыха в доме.

## Устройство игры

- [farm.ts](src/farm.ts) хранит правила и версию состояния. Модуль можно тестировать в Node.js без браузера.
- [island.ts](src/island.ts) управляет маршрутами, анимациями и выбором целей. Координаты игрового поля общие для мыши, сенсорного ввода и клавиатуры.
- [world.ts](src/world.ts) собирает остров, воду, растровые объекты, наземные тени и объёмные детали в одной ортографической сцене Three.js. Для игры нужен WebGL2. После восстановления графического контекста мир снова отображается.
- [occlusion.ts](src/occlusion.ts) задаёт положение фрагментов исходной иллюстрации, которые закрывают персонажей, когда те оказываются позади.
- [water.ts](src/water.ts) задаёт движение воды в той же сцене. Шейдер получает альфа-силуэт острова для береговой пены и положения лодки и поплавка для ряби.
- [main.ts](src/main.ts) связывает состояние, HTML-панели и локальное сохранение. TypeScript и Vite используются для разработки и сборки.

## Графика

Растровые ассеты в [public/art](public/art) сгенерированы встроенным ImageGen по [основному референсу](../01_primary_target/main_gameplay_reference_cozy_smooth.png). Отдельные объекты и листы кадров генерировались с настоящей прозрачностью. Для игры их уменьшили и закодировали в WebP с сохранением альфа-канала. Сплошная иллюстрация воды движется отдельными слоями с бликами, рябью и покачиванием лодки.

В промптах для объектов использовались общие условия: отдельный объект в кадре, фронтальная ортографическая проекция с наклоном камеры около 40°, тёплый утренний свет, гладкие округлые формы и настоящая прозрачность по контуру. Ассеты должны оставаться различимыми в игровом масштабе.

| Группа | Что запрашивалось |
| --- | --- |
| Острова | По одной цельной иллюстрации на остров. Рельеф, постройки, дорожки, посадочные ряды, ограда и лестницы нарисованы вместе, с общей ортографической камерой, утренним светом и матовым деревом. Saltwind Grove использует тот же ракурс и песчаную бухту. |
| Вода | Бирюзово-синие волны сверху, мягкие блики и каустика. Сгенерированная текстура служит основой шейдера. |
| Мельница | Четыре полотняных крыла с круглой осью, согласованные по материалу с башней на острове. Ротор вращается вокруг нарисованной ступицы. |
| Персонажи | Фермер в соломенной шляпе с циклами ходьбы спереди и со спины, покоем, рыбалкой и движениями для четырёх действий на грядке. Два листа по четыре кадра для ходьбы курицы и взмахов крыльев. |
| Окружение | Три вида фруктовых деревьев с кадрами от саженца до плодоношения, камни, цветы, ящики, причал, лодка и цельная изгородь. |
| Культуры | Семь листов по девять кадров. Группа из четырёх растений растёт на общем грунте, держит опору и меняет размер постепенно. Зрелый кадр и золотая метка появляются, когда участок можно собрать. |
| Иконки | Предметы, постройки и ресурсы с единым освещением, рассчитанные на чтение в панели инструментов и меню. |

Рендерер совмещает соседние кадры роста, проецирует силуэты спрайтов на грунт и учитывает высоту при движении кур. Посев, полив и сбор обновляют состояние на контакте инструмента с землёй. Три быстрых нажатия на один участок выполняются по очереди. В режиме снижения движения действия выполняются сразу. Прошлые сохранения получают новые поля при загрузке.

Для новых генераций используйте [руководство проекта по ассетам](../08_docs/ASSET_USAGE_GUIDE_RU.md).
