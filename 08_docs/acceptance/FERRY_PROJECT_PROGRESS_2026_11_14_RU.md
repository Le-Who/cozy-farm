# Что изменит выбранная поставка

## Узкий срез

База: опубликованный `8bd6e026`. Существующий паром уже показывает направление, два заказа, зафиксированный груз/расчёт, возвращение игровым утром, получение, разведку и пополнение запасов. Эти механики не переписывались.

Вместо общей фразы о помощи порту выбранный груз показывает конкретный вклад в существующий проект и его пользу. Например: «Вторая печь», «Пшеница: 8 → 10/10», затем работа печи после доставки. Для проекта из нескольких продуктов видны и изменяемые, и ещё недостающие позиции. Пока проект не завершён, результат явно описан как польза **после завершения проекта**, а не обещание за одну неполную поставку.

- Предпросмотр ничего не списывает и не выдаёт. Дефицит личных запасов по-прежнему блокирует отправку.
- Для рейса в море используется его зафиксированный груз. Прибывший груз уже учтён в накопленных поставках, поэтому для его карточки вклад не прибавляется повторно.
- Чистая покупка, разведка, не относящийся к проекту груз и уже завершённый проект не получают ложного прогресса.
- Когда виден этот предпросмотр, прежний раскрывающийся раздел называется «О порте»: второй конкурирующей сводки проекта рядом нет. Всё прежнее подробное содержимое сохранено. Без предпросмотра остаётся прежняя подпись с текущим прогрессом.

Новых кнопок, наград, цен, ожидания, полей сохранения, звуков, анимации, ассетов и изменений кухни нет.
