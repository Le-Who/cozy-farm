# Lavender Bay: авторская кухня и живая заводь

Рабочая версия проекта в `game/`. Приёмка относится к локальным изменениям после `3cbefce`; это не утверждение о публикации в GitHub.

Финальная production-сборка: `index-DX-47Kkv.js`, `index-BTW5JQR_.css`, `workshop-cut-worker-CccrLeeP.js`. **234/234 теста**, TypeScript и сборка прошли. [Точные версии и результаты через родительский интерфейс](production-verification.json), [полный вывод тестов](test-results.txt), [сценарии готовки и SHA-256 исходников](cooking-physical-final-ledger.json). Хеши всех 12 файлов из последнего документа сверены с финальными исходниками. В нём отдельно обозначен локальный адаптер; производственные списания подтверждает координатор через основную игру.

Нативные записи груши и печенья сделаны через обычные меню production-приложения на `index-zvbs654r.js`; соответствующие исходники медовой кухни совпадают с финальными. Последняя сборка дополнительно исправляет возврат осевших фруктов в обычное размешивание варенья; этот полный путь проверен уже на `index-DX-47Kkv.js`.

- `signature-studio-portrait.png`, `berry-tart-rotated-portrait.png`, `signature-book-portrait.png`: на валидированном сохранении с выданными ингредиентами пройдены выбор обычной клубники и морозной черники, ручное размещение и вращение мышью/клавиатурой/двумя touch-указателями, посыпка, сохранение, имя, избранное и партия ×3. В итоговых запасах списаны конкретные выбранные ингредиенты, яйцо и пшеница; расположение и угол сохранены.

## Ограничения метода

Touch-проверки используют настоящие события Chromium через CDP; физический телефон не использовался. Изолированные расширенные состояния помечены как fixtures и не выдаются за новое сохранение. Статичный снимок не доказывает плавность: записи движения находятся в локальном `output/playwright/`, а визуальная приёмка учитывает действия, отпускание, затухание и переходы состояний.

Для проверки записей сервер должен поддерживать перемотку по byte ranges. Аудит сверяет `seeked`, декодированное время кадра и плотные выборки движущихся существ; несколько повторно декодированных кадров из нулевой отметки не доказывают статичность записи.
