## Следующая узкая нативная проверка

```sh
npm run dev -- --port 4272
```

Открыть `http://127.0.0.1:4272/tests/manual/workshop-controls.html`. Стенд использует настоящую `createWorkshop`, не читает и не пишет ферму. Сначала замесить тесто, затем проверить все шесть инструментов мышью / касанием. После каждого выбора нажать «Проверить элементы»: ожидается `pass: true`, пустой `issues` и совпадение видимого режима с выбранным действием. Для закрытой палитры дополнительно открыть её ладонью и повторить измерение. Проверить переход к выпечке и возврат.

В первую очередь проверить **520×480** с длинными подсказками: расчёт комнаты оставляет небольшой промежуток между подсказкой и палитрой. Нужны реальные шрифтовые метрики, поэтому возможное перекрытие пока не объявляется воспроизведённым игровым дефектом. Новая диагностика сообщит `covers-mode-guide`, если оно есть.

Более тесные рабочие области (например, 480×320 и 200% масштаб) также требуют отдельной проверки. Геометрическая гарантия выше относится только к шести перечисленным размерам.
