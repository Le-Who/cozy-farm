# Парфе, варенье и ручная готовка

Интерактивные сцены проверены в Chromium через интерфейс игры. Для доступа к поздним рецептам использованы отдельные сохранения с открытой кухней и запасом продуктов.

| Что проверить | Наблюдаемый результат |
|---|---|
| Парфе | Три порции крема переносятся из миски. Ложку можно быстро отпустить над бокалом или держать до опустошения. После трёх долек кувшин льёт мёд до поверхности. На финальном кадре видны целая веточка лаванды и кремовая верхушка с исходного художественного листа. Мёд, яйцо и персик списаны по одному. [Запись на мобильном размере](parfait.webm) · [Готовый бокал](parfait.webp) |
| Личный тарт с обычной и морозной черникой | У края начинки можно оставить ягоду. Иней сохраняется на выбранной порции после выпечки, записи рецепта и загрузки игры. [Тарт](tart.webp) |
| Радужный и морозный конфитюр | Свойства видны внутри варенья. Бант, ткань, передние плоды, блик и основание банки сохраняют исходные цвета. [Сервировка у Беа](jar.webp) · [Миниатюры](jar-book.webp) · [Сравнение с исходным рисунком](jar-detail.webp) |
| Покрытие на разных изображениях | Одна и та же отделка подогнана к пяти рисункам для интерфейса и двум для кухни. Проверены защищённые точки, изменение цвета внутри варенья и исходная прозрачность по всей площади каждого изображения. |
| Нарезка и полив груши | Частичный надрез сохраняется после отпускания ножа. Его можно продолжить мышью, пальцем или клавишами. Мёд остаётся на пройденном участке мякоти. [Надрез](knife.webp) · [Полив на узком экране](pear.webp) |
| Формование теста | Образец выбирается вверху. Инструменты открываются у руки. Перекатывание скалки рядом с тестом не меняет выбранный инструмент. Проверены длительное удержание и раскатка на сенсорном экране. [Мастерская](workshop.webp) |
| Смена дерева | Внутри окна дерева можно выбрать соседнюю посадку. Сбор плодов с груши оставляет плоды на яблоне. [Сад](trees.webp) |

Для записей, созданных до сохранения особенностей отдельных кусочков, игра восстанавливает отделку по порциям из состава рецепта. Новые записи хранят особенность вместе с положением и поворотом каждого кусочка.
