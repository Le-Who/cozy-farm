# Музыкальный сад: проверка нового интерфейса

9 ноября 2026. Рабочая игра на локальном Vite, обычный вход через «Открыть бухту» → «Музыкальный сад». Исходное сохранение — `game/.playwright-cli/bay-harbour-state.json`, адаптированное к локальному порту 5351.

Сцена оставляет инструменты и одну выбранную дорожку на экране. Мелодии, настройка и материалы открываются отдельными листами. Корень сцены не прокручивается. У листов один прокручиваемый блок; действия сохранения и материалов закреплены отдельно.

Проверены 1440×900, 390×844, 360×640, 568×320, 844×390, 520×480, дополнительно 390×568. Горизонтального переполнения и обрезанных главных кнопок нет; одновременно видны transport, 16 шагов, ноты и возврат. На 568×320 у листа материалов закрытие занимает y22–64, обе кнопки y250–294.

Нативные действия в Chromium: выбор инструмента, изменение и удаление ноты, переключение высоты клавиатурой, имя и сохранение версии, очистка выбранной дорожки, восстановление версии и темпа, mute дорожки, старт/стоп и движущийся такт. Настоящие touch events через CDP выбрали инструмент и записали ноту в сохранённый рисунок. Escape закрывает лист и возвращает фокус на вызвавшую кнопку. Из листа материалов открыт паром; его «Назад» восстановил лист, инструмент, высоту, слот и фокус кнопки парома. После перезагрузки сохранены название, слот, записанные ноты и счётчик выступлений.

Повторяемые драйверы: `game/scripts/qa/bay-music.js` (15 проверок) и `game/scripts/qa/bay-music-silent.js`. Их запускают через `playwright-cli run-code --filename` при открытом саде первого уровня из указанного QA-сохранения. Они меняют только данные браузерного QA-профиля.

Режим тишины проверен отдельно при muted=true, volume=0, music=0. Во всех трёх режимах воспроизведение шага, редактирование и запись работают; обёртка настоящего audio singleton зафиксировала 0 вызовов primeInstruments. Нет ошибочного сообщения о недостающем тембре. После стопа счётчик callback draw не меняется (48→48, 95→95, 142→142). Возврат громкости с нуля через настоящий slider вызывает один прогрев инструментов и оставляет транспорт запущенным.

`npm test`: 326 пройдено, 0 ошибок. `npm run build`: успешно, русский аудит — 0 непереведённых строк. Сохраняется предупреждение Vite о крупных chunks.

`desktop.png`, `portrait.png`, `landscape.png` — финальная композиция. `materials-portrait.png`, `materials-landscape.png` — раскрытый маршрут к материалам с закреплёнными действиями. `performance.webm` — клавиатурная игра и переключение инструментов на финальной версии, такт и отклик объектов.
