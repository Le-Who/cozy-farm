# Навигация, мастерская и кухня гавани

Проверки выполнялись через обычные экраны игры с отдельными сохранениями поздней фермы. Для проверки движения и подсчёта яиц использовалась также самостоятельная сцена укладки с тем же контроллером.

| Действие | Что подтвердилось |
| --- | --- |
| Открыть инкубатор на узком экране | Курочки помещаются по три в ряд. Кнопки кормления и сбора занимают по одной строке с названием, где это допускает ширина. [Кадр](incubator.webp) |
| Перейти между островами и домиками | Пиктограммы переключают одну подробную карточку. Домик показывает своего жильца. Переход и возврат проверены касанием и клавиатурой. [Острова](islands.webp), [соседи](neighbors.webp) |
| Выбрать неизвестный батон у Беа | Указанный образец открывается в мастерской, сохраняется после выпечки и становится доступен для заказа у Беа. [Запись выпечки](../workshop/loaf-proofing.webm) |
| Приготовить собственное угощение на встречу | В гавани открыт обычный рецепт, затем испечён собственный тарт из черники и клубники. Готовая порция доступна у Беа. Сервировка списала одну порцию и записала её название в память встречи. [Результат](tea.webp) |
| Перенести предметы в корзинку | При нажатии и удержании выбранная точка остаётся у пальца. После трёх жестов с продуктами, трёх с яйцами или пяти для ящика появляется готовность. Для каждой раскладки получена одна выдача. [Корзинка](picnic.webp), [ящик](eggs.webp) |
| Выбрать улов | Четыре вида доступны на гриле. Проверены списание именно выбранной рыбы, восстановление сохранения и прежние рецепты без указания вида. [Лунная рыба](moonfish.webp) |
| Осмотреть отмель или обустроить заводь | [Отмель](shoal.webp) показывает сегодняшние находки. В [заводи](cove.webp) видны последствия обустройства для течения, улова и обитателей. |
