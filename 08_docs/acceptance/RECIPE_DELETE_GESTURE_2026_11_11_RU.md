# Один жест удаления пустого рецепта

Дата: 11 ноября 2026. База: `d30fbf39da09dce082d2a0680882e642421a179b`.

## Подтверждённая проблема

В обычной книге рецептов реального `main.ts`, без подмены обработчиков, один double-click по нижней кнопке «Удалить пустой рецепт» удалял два разных рецепта. После первой перерисовки следующая карточка занимала то же место. В принятой `restoreFarm` синтетической ферме с пустыми `s1`, `s2`, `s3` после одного жеста оставался только `s3`. Это воспроизведено при размере игры 568×320 до правки. Данные не являются историческим сохранением игрока.

## Узкая правка

`forget-signature` добавлен в существующий список защищённых действий. Capture-обработчик удерживает один pointer-жест после перерисовки, в том числе когда браузер сбрасывает `click.detail` у нового элемента. Обработка удерживаемого Enter использует уже существующую защиту активации.

Правила удаления, точные ID, составы рецептов, избранное, запасы, экономика и формат сохранения не изменены. Новых диалогов, подтверждений или задержек для отдельного намеренного действия не добавлено. Существующая доменная проверка по-прежнему запрещает удаление рецепта с порциями, избранного или складского рецепта. Обновлено описание существующего `menu.press`: повторный поглощённый клик не вызывает второй звук. Записи и параметры аудио не менялись.

## Actual UI после правки

Изолированный origin `http://127.0.0.1:4209/tests/manual/recipe-delete.html`. Видимая кнопка готовит только синтетическое сохранение этого origin. Книга открыта обычным путём «Открыть бухту» → «Мои рецепты». Проверены 568×320 и 844×390.

- Один double-click удаляет только `s1`; `s2` и `s3` остаются, `serial=3`, монеты 18 и `workToday=3` не меняются.
- Полная перезагрузка сохраняет `s2` и `s3`, правильные имена и нулевой запас.
- Отдельное нажатие Enter удаляет выбранный `s2`. В отдельном сценарии это же делает независимый последующий click.
- Добавление оставшегося `s3` в избранное убирает кнопку удаления. Возврат из избранного восстанавливает её.
- «Повторить ×1» готовит одну порцию оставшегося `s3` без нового ID; кнопка удаления исчезает. После reload сохранены `stock.s3=1`, `serial=3`, `workToday=4`, монеты 18.

Это проверка реальных DOM-меню в штатном браузере без WebGL2. 3D для этого сценария не нужен и не запускался; общий renderer не занимался. Нативное удержание клавиши не проверялось отдельно, его защита покрыта автоматическим тестом. FPS и плавность не оценивались.
