# Восстановление режима «В своём ритме»

База: `27de2c0`, отдельная ветка `dot/restore-cozy-own-pace`. Только локальный коммит, без push. Это новая минимальная реализация подтверждённого поведения, не утверждение о восстановлении прежнего исходного кода или его схемы данных.

## Подтверждённое поведение

Подсказки можно убрать, а выбранную задумку сохранить и позже вернуть, в том числе после перезагрузки. Дополнительных подробностей прежнего UX не было, поэтому новые игровые цели, награды или автоматические действия не добавлялись.

## Реализация

- В дневнике можно выбрать текущую предложенную задумку, включить «В своём ритме», вернуть задумку или снять выбор. Тихий режим скрывает автоматическую HUD-карточку; контекстные действия у выбранной грядки и навигация остаются доступны.
- В `discoveryPreferences` сохраняются только `quiet` и текстовая запись `{id,label,detail}`. При отсутствии поля старое сохранение получает обычные подсказки и пустой выбор. Значения строго проверяются по типам, длине и управляющим символам; команды, прогресс и награды не входят в запись.
- Выбранная задумка не заменяется автоматически. Если та же задача ещё актуальна, её действие и прогресс вычисляются заново. Если задача уже изменилась, HUD показывает сохранённую запись без старой награды/счётчика и открывает дневник, а не выполняет прежнюю команду. Возврат из тихого режима сам не собирает урожай, не продаёт вещи и не начинает новый день.
- Текст сохранённой записи экранируется при выводе. Формат v3 не менялся, новое поле обратно совместимо для чтения старых сохранений текущей сборкой.

- `npm test`: 543/543. Девять новых тестов: загрузка без нового поля, отсутствие экономических изменений при выборе/скрытии/возврате, четыре коротких захода с действиями/сном/reload, сохранность выбора, безопасное устаревание, актуальные вычисляемые действия, отказ устаревшему выбору, независимые копии, строгая валидация, экранирование и явные UI-кнопки.
- `npm run build`: проходит, включая TypeScript и аудит русского. Прежнее предупреждение о крупных чанках остаётся.
- `git diff --check`: проходит.
- CUA, actual main на отдельном localhost:5195: создана синтетическая ферма без перезаписи существующих данных. Карта → дневник → выбор «Подготовьте грядку» → «В своём ритме» → закрытие → reload: HUD-карточка отсутствует.
- Затем через настоящий курятник собрано одно яйцо, выполнен ещё один reload: подсказки остаются скрыты, выбранная задумка сохраняется. Проверочная страница читает валидное v3: `quiet=true`, `idea.id=till`, 23 монеты, 1 действие, `collect=1`.
- На iframe 390 px открыт настоящий дневник клавишей J, выполнен возврат к задумке. HUD-карточка вернулась. Повторное чтение v3 показывает `quiet=false`, тот же текст и id; 23 монеты, 1 действие и весь прогресс остались прежними. Переключение режима не выдаёт награду.
- Дневник осмотрен на desktop и 390 px: кнопки читаются, на узком экране размещаются вертикально. Контекстная помощь грядки остаётся доступной и в тихом режиме.
