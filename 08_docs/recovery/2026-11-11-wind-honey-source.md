# Точный источник мёда ветров

## Подтверждённый барьер

В actual main на игровом дне 9, при пасеке уровня 3, трёх цветущих клумбах и последнем сборе в день 8, ссылка «Мёд ветров, 0 из 1» из медовой кухни выделяла «Улей мыса · Собрать мёд». Доступный сбор содержал только 4 порции обычного мёда и 1 воск. Ближайший редкий мёд был доступен лишь в день 13. Дата и различие нужного вида не объяснялись.

## Изменение

- Отдельный read-only прогноз проверяет `getCapeHoney` на текущем и следующих семи игровых днях. Формула погоды, рост, квоты, награды и схема сохранения не изменены.
- Ссылка редкого ингредиента и общая подсказка открывают пасеку с точной датой и количеством, а не предлагают обычный мёд как нужный. При пустых клумбах предлагается явная посадка. Закрытый мыс не обещает дату. Готовый местный склад сохраняет приоритет.
- Пасека показывает прогноз по нынешним клумбам. Обычный доступный сбор остаётся отдельным выбором. Переход домой открывает прогноз отдыха; ночь начинается только по «До утра».
- Мёд ветров не получил искусственного требования улучшения: по действующему правилу достаточно открытого мыса и одной цветущей клумбы.

## Проверки

- 767/767 тестов; сборка TypeScript/Vite прошла. 9 новых тестов, включая матрицу 360 состояний дней 1–30, уровней, молодости клумбы и использованной квоты.
- Проверены начало календаря, границы 7/8/9 и 12/13, использованный сбор, пустые и молодые клумбы, закрытый мыс, safe integer, неизменность состояния, reload и повторный расчёт изменившихся условий.
- Доменно: явные ночи 9→13, возвращение и один `collectCapeHoney` дали ровно 3 обычного мёда, 1 мёд ветров и 1 воск. Повторный сбор отказал без изменений. На уровне 1 одна взрослая клумба рядом с молодой дала ровно 1 редкую порцию, без обычного мёда/воска.
- Actual UI, desktop и iframe 390×844: double-click по ссылке ингредиента на днях 9 и 12 открыл прогноз дня 13 без изменения точных v3 bytes. Назад вернул медовую кухню. Просмотр не расходовал сбор.
- Actual UI: double-click «Домой к отдыху» при доступном обычном мёде изменил строго только остров. Полный JSON совпал с baseline с заменой `island`; день 12, монеты 18, work 0, корм и `capeHoneyOn=8` не изменились.
- Actual UI: явное «До утра» дало день 13; reload, возвращение на мыс и повторная ссылка показали актуальные 3 обычных + 1 редкий мёд + 1 воск. Автосбора не было.
- WebGL2 недоступен: нажатие «Собрать мёд» закрыло панель, но прежний `workCape` не запустил сбор без сцены. Успешное получение проверено доменно, не заявляется как GPU/UI pass. Обход графического ограничения не добавлялся.
- Обновлены описания существующего `page.unfold`; маршрут выполнен через обычный UI. Каталог пересобран, runtime и dist audio audit прошли: 164 записи, 152 эффекта, максимум −6.34 dB, нет missing/unreferenced.

Изолированный проверочный стенд: `game/tests/manual/wind-honey.html`, только localhost/127.0.0.1:5212. Создаёт синтетическую ферму явной кнопкой лишь при отсутствии v3/v2; существующее сохранение не заменяет. `game/scripts/qa/wind-honey-mobile.html` открывает actual main в 390×844.
