# Ближайший посаженный источник урожая

## Воспроизведение

База `8d8cca0`, настоящий маршрут «Карта → Дом → Кухня → Где найти: Пшеница».

- День 3: первая пшеничная грядка — новый сухой посев 0/2, вторая — политая 1/2; пшеницы в сумке нет.
- Дом правильно показывает одну грядку к сбору утром. Однако кухня отправляла к первому новому посеву, предлагая ненужный для ближайшей порции полив.
- Причина: `cropSource` выбирал первую сухую грядку, независимо от зрелости, и лишь после отсутствия всех сухих предлагал отдых.

## Изменение

Чистый helper выбирает среди посадок нужной культуры минимальное число оставшихся шагов роста. При равенстве уже политая грядка имеет приоритет. Готовая грядка остаётся первым источником. Сухая более зрелая посадка по-прежнему требует явного полива либо наполнения лейки; не отправляет спать до полива. Если ближайшая уже полита, подсказка объясняет, что она подрастёт этой ночью.

Это сравнение при обычном явном уходе, а не прогноз многодневного созревания без полива. Бесплатное пополнение воды, рост, погода, урожай, награды и обработчики действий не изменены. Завтрашний дождь не считается поливом для текущей ночи. Местный склад и готовые редкие источники сохраняют прежние более ранние проверки. Новых аудиособытий или обработчиков звука нет.

## Проверки

- Девять новых тестов: готовый урожай, разный возраст и полив, равная зрелость, отсутствие воды, смена берега/состояния, чистота подсказок, reload и получение урожая.
- Матрица всех культур на днях 1–22 сверена с фактическим `endDay`: сухая грядка не растёт этой ночью даже перед дождём; явно политая почти зрелая созревает. Не требуется угадывать погоду для ранжирования при доступном явном уходе.
- Полный набор **738/738**, `npm --prefix game run build` PASS, `git diff --check` PASS. Сборка выдаёт прежнее предупреждение о размере чанка.

2. На экране 390×844 явно открыт дом и нажато «До утра». День стал 4, только вторая грядка выросла 1/2 → 2/2; первая осталась сухой 0/2, вода 2. Начальная цель отдыха выдала свои существующие 4 монеты: баланс стал 22. Новых наград этот пакет не добавляет.
3. После reload та же кухонная ссылка, также двойным нажатием, ведёт к готовой второй грядке. Состояние до отдельного сбора не изменилось. Контекст «Пшеница · Обычные ×3 · Собрать +3» проверен визуально на 390 px.
