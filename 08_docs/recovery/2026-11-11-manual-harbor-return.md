# Возвращение к ручным заказам причала

## Подтверждённый барьер

На базе `5578919` в настоящем маршруте «Острова → Солёная роща → Заказ гавани» завершённая ручная посылка показывала только прежний состав и «✓ Доставлено». Не было объяснения, когда появится следующая, что можно подготовить, и прямого пути к отдыху. Это не грузовой паром.

Для завершённого «Ужина в гавани» на дне 3 проверен последующий обычный цикл: явное плавание домой и «До утра» дали на дне 4 «Посылку из Солёной рощи» с домашним хлебом ×1 и солью ×2. Тот же состав заранее возвращает существующий `getHarborOrder` при просмотре следующего дня.

## Изменение

- Только завершённый ручной заказ показывает состав после следующего игрового утра, вычисленный через `getHarborOrder`, без отдельной копии меню.
- Текст явно ограничивает прогноз нынешним основным направлением кухни и сообщает, что припасы автоматически не отправляются. Будущая награда не прогнозируется.
- Ссылки ингредиентов используют имеющиеся способы поиска. Это подготовка, не доставка.
- «К отдыху дома» открывает обычный прогноз дома. Новый обработчик проверяет текущий день, завершённость заказа и открытую карточку гавани либо вкладку заказов рынка. Общая защита отделяет double-click/удерживаемый Enter от действий появившейся панели.
- Ручная доставка, возврат неполной посылки, квоты, награды, сохранённые данные, стоимость и грузовой паром не изменены.

## Actual UI

Защищённый fixture создаёт синтетическую ферму явной кнопкой только на loopback:5211; имеющаяся v2/v3 ферма не заменяется.

1. В новой карточке на 390×844 видны день 4, название посылки, хлеб 0/1, соль 0/2, условие прогноза и кнопка отдыха. Карточка визуально помещается, текст не перекрывается. Просмотр оставил точные bytes v3 неизменными.
2. Double-click «К отдыху дома» из рощи открыл дом. Сравнение всех полей до сна показало изменение только `island`: день 3, 60 монет, работа 1, completed=1, deliveredOn=3, пустой резерв и продукты прежние.
3. После reload та же карточка проверена внутри рыночных заказов. Её double-click также только открыл дом; сохранение не поменялось дополнительно.
4. Явное «До утра» перевело игру на день 4. После reload в рынке уже текущая «Посылка из Солёной рощи», хлеб 0/1 и соль 0/2, кнопка «В рощу», без следующего прогноза. Монеты остались 60, число завершений 1, припасы не отправлены. Обычные ночные изменения остальных циклов выполняются прежним `endDay`.

Ограничение: WebGL2 недоступен. Проверены реальные HTML-панели, обработчики перехода, сохранения и ночной цикл; графическая сцена путешествия не оценивалась. Сохранность неполной посылки и смена основного направления кухни проверены доменными тестами, а не заявлены как отдельные новые UI-прогоны. Изменение не опубликовано.
