# Восстановление возвратного цикла заводи

База: `0d864da`, отдельная ветка `dot/restore-cozy-cove-return`. Только локальные изменения, без push.

## Восстановлено

- Явная отмена ещё не применённого плана заводи. Удаляется только `shoreline.pending`: действующее обустройство, открытия, ревизия, ресурсы, дневные счётчики и начатая рыбалка не меняются. Применённый прилив отменить нельзя.
- Кнопка передаёт ключ показанного плана. Устаревший клик не отменяет другой план, а повторная отмена ничего не меняет. Ключ вычисляется из существующих полей, новых полей сохранения нет.
- Панель разделяет нынешний берег и прогноз на конкретный следующий день, включая течение, растения, укрытие и эффект для рыбалки. Прогноз вычисляется на отдельной копии, без раннего применения или выдачи наблюдений.
- После реального применения плана `endDay` сообщает о приливе. Панель подтверждает его в день применения, в том числе после перечитывания сохранения. На следующий день без нового плана подтверждение не повторяется.
- Панель ограничена высотой экрана и прокручивается на низком экране. Физика, награды, цены, материалы, аудио и механика применения прилива не менялись.

## Проверено

- `npm test`: 491/491, включая восемь новых тестов домена/UI. Покрыты отмена первоначального и нового плана поверх применённого, отказ после применения, отсутствие возврата ресурсов/прогресса, устаревший клик, ограничения доступа, сохранность текущего рыболовного снимка, JSON roundtrip до и после отмены, отсутствие повторного применения, точное соответствие прогноза утренней экологии и неизменность данных при просмотре.
- `npm run build`: проходит, включая TypeScript и аудит русского. Осталось прежнее предупреждение о крупных чанках.
- `git diff --check`: проходит.
- CUA, Chromium, изолированная страница `game/scripts/qa/cove-return.html`: выбор открытого течения → прогноз дня 2 → отмена → JSON roundtrip. Затем открытое течение + камни → отдых дома → день 2, одна ревизия и четыре наблюдения → JSON roundtrip → новый план тихого течения → отмена с сохранением открытого течения и ревизии 1.
- На ширине 390 px проверены прогноз, читаемость и рабочая отмена. Панель целиком помещается в высоту iframe: нижняя граница 824 при viewport 840, внутреннего переполнения нет.

## Границы проверки

Harness использует реальные `coveControls`, `changeCove`, `cancelCovePlan`, `endDay` и `restoreFarm`, не читает и не изменяет сохранения браузера. Это проверка панели и доменного цикла, не полного маршрута через main. Движение животных и рыболовная сцена не менялись; браузер среды не поддерживает WebGL2, их визуальная проверка не заявляется.
