# Понятный путь к редкой рыбе

База: `0229af9`. Новое узкое улучшение по результатам игрового аудита, не попытка восстановить неизвестную старую реализацию. Только локальная разработка, без публикации.

## Подтверждённый барьер

В настоящей кухне выбор лунной рыбы для гриля и ссылка недостающего ингредиента отправляли игрока без лодки на рынок: сначала заработать на лодку за 36 монет. При этом существующая модель позволяет встретить лунную рыбу и рыбу-фонарь у обоих рыбацких берегов. Глубина, а не обычный вид рыбы этого берега, определяет редкую находку.

## Изменение

- Подсказка выбирает текущий доступный берег с оставшейся квотой, затем другой достижимый берег. Лодка не нужна для поиска редкой рыбы дома. Обычный окунь и морской окунь сохраняют прежние региональные требования.
- Если доступные берега исчерпаны, подсказка ведёт домой к панели отдыха. Сон остаётся отдельным явным действием.
- Кухня сохраняет обратный путь. Открытие рыбалки не начинает заброс и не расходует квоту, подготовку, помощь Финна или пикник.
- Подсказки кухни, общего следующего действия и коллекции уточняют шанс: лунная рыба может встретиться примерно на 75–100 м, рыба-фонарь глубже 100 м. Улов не гарантирован.
- Реальный double-click по новой ссылке в компактном интерфейсе сначала открывал рыбалку, затем попадал в появившуюся fallback-кнопку «На берег». `show-requirement` добавлен в существующую защиту повторного нажатия и удерживаемой клавиши. Правила улова не менялись.

Модель рыбалки, выдача наград, лимиты и формат сохранения не менялись. Описания существующего `page.unfold@2` обновлены по аудиокаталогу; новых звуков и внешней генерации нет.

## Проверка

11 новых тестов проверяют оба редких вида, доступность берегов, квоты и бонус восстановленного причала, reload, неизменность данных при подсказке, границы глубины, отсутствие обещания редкой рыбы в каждом seed, обычный явный заброс/однократную выдачу и защиту повторной активации. Удерживаемая клавиша проверена модульным тестом; обычный Enter проверен в интерфейсе.

Настоящий `main.ts` через CUA, отдельные loopback origins 5203/5204, desktop и iframe 390×844. Проверочная ферма создаётся только явной кнопкой, существующее v2/v3 не заменяется. Исходное сохранение заранее нормализовано `restoreFarm`.

1. День 5, дом, без лодки, 18 монет, квота 0/3. Кухня → лунная рыба → рыбалка → «Назад: Кухня», затем рыба-фонарь → рыбалка. Выбранный вид сохранился при возврате. Точная строка v3 осталась прежней, токен null, serial 0, рыбы 0.
2. С подготовленной рыбалкой, сохранённой помощью Финна и пикником bright/day5: double-click ссылки на экране 390 оставил рыбалку открытой. После возврата и reload `saveBytesUnchanged=true`, day5, work4, квота0, token null, serial0, scouting=true, finnHelp=true, пикник прежний.
3. Квота дома 3/3, лодки нет, те же бонусы: double-click ссылки открыл дом с «Назад: Кухня», не сон. После возврата, reload и повторного перехода через Enter точные v3 bytes прежние: день5, work4, 18 монет, квота3, бонусы на месте, рыбы0.
4. Только явный double-click «До утра» дал день6 один раз. После reload квота0, 18 монет, рыбы0, token null, serial0; пикник истёк по прежним правилам, scouting и помощь Финна сохранились. Кухонная ссылка снова открыла рыбалку, возврат сохранил выбранную лунную рыбу.

Ограничение: WebGL2 на стенде отсутствует. Проверены настоящие переходы, доступность, fallback, возврат, сохранение и утро, но не визуальное появление редкой рыбы и не игровой захват крючком. Наличие видов, глубина, расход бонусов при явном забросе и выдача улова подтверждены доменными тестами, не GPU-прохождением.

Итог: `npm test` — 662/662; `npm run build` — успешно (обычное предупреждение о размере чанка). Пересборка аудиокаталога, runtime/dist аудиты и `git diff --check` успешны.
