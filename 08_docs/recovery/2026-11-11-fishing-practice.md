# Восстановление тренировочной рыбалки

База: `d7e5f91`, отдельная ветка `dot/restore-cozy-fishing-practice`. Изменения только локальные, без push.

## Восстановлено

- После дневной квоты текущего острова предлагается отдельная кнопка «Тренироваться без наград». Она есть в меню причала и после последнего обычного улова. Обычный заброс не превращается в тренировку автоматически.
- У тренировочного режима есть постоянное обозначение отсутствия улова, опыта и прогресса, явная кнопка «На берег», повторная тренировка и отдельное сообщение результата.
- Тренировочный сеанс существует только в памяти. Его callbacks не получают доступ к ферме, не создают токен обычной рыбалки, не расходуют бонусы, не вызывают выдачу наград или сохранение. Любые рыбы, ракушки и мусор отбрасываются. Закрытый сеанс не принимает устаревшие результаты; старый callback также не закрывает новый сеанс в main.
- Обычные награды, дневные лимиты, дополнительный улов достроенного причала, схема сохранения, физика, материалы и аудиособытия не менялись.

## Проверено

Девять новых тестов покрывают местную квоту и обе локации, дополнительную квоту причала, запрет входа при обычном незавершённом забросе, полный неизменный FarmState на замороженных данных, бонусы, успешный и пустой улов модели, раннюю отмену, повторный результат, старый callback при новом тренировочном/обычном сеансе, восстановление JSON без токена наград, обычную выдачу рыбы и явный вход в UI.
- `npm run build`: проходит, включая TypeScript и аудит русских строк. Существующее предупреждение о больших чанках остаётся.
- `git diff --check`: проходит.
- Через CUA в Chromium открыта локальная изолированная страница `game/scripts/qa/fishing-practice.html`: выполнены вход и «На берег» для дома и рощи, повторный вход, узкий экран 390 px. Полный снимок фермы после входа/выхода не меняется. Предупреждение и обе кнопки выхода видны без перекрытия. Harness использует реальные renderFishingPracticeEntry/createFishingGame и session helper, не читает и не меняет браузерные сохранения.

## Ограничения проверки

В браузере среды недоступен WebGL2: реальный renderer переходит в штатное сообщение ошибки. Проверены вход, обозначение режима, доступность выхода при отказе renderer и сохранность данных. Визуально проверить физический заброс, результат и звук не удалось; успешный и пустой заброс проверены тестами модели и тренировочного сеанса. Изолированная страница не заменяет smoke маршрута через полный main после интеграции.

## Дополнительная проверка настоящего игрового интерфейса

На общей интеграции `0d864da` через видимый localhost-only fixture `tests/manual/recovery.html` создана валидная ферма с исчерпанной домашней квотой 3/3. В настоящем `main.ts` нажаты удочка → «Тренироваться без наград» → «На берег», затем открыта отдельная проверочная страница.

Основной интерфейс показал отдельный режим без наград и явный выход. Доступный браузер снова выдал WebGL2 fallback, поэтому физический заброс здесь не проводился. После выхода и загрузки проверки сохранение осталось валидным, квота 3/3 сохранилась, монеты и все запасы прежние. Сравнение точной строки v3 с исходной строкой в тестовом sessionStorage показало `practiceSaveBytesUnchanged: true`: вход и выход тренировки вообще не переписали пользовательский прогресс.
