# Один жест действия грядки

## Подтверждённая ошибка

См. реальный 3D проход в `2026-11-11-full-garden-source.md`. Двойной клик кнопки «Собрать +3» заранее добавлял две работы. После сбора вторая работа заново читала грядку и уже сеяла выбранную пшеницу, расходуя одно семя без отдельного решения.

## Узкая защита

Только `work-context` добавлен в существующий `ActionClickGuard`. Он подавляет повторные клики одного жеста и повтор удерживаемой Enter/Space, в том числе при перерисовке кнопки. Новое отдельное нажатие по-прежнему допускается. Механизм очереди, мир, доменные операции, цены и награды не менялись.

Четыре регрессии сначала упали на прежнем коде, затем проходят. Пятая отдельно проверяет новое клавиатурное подтверждение после клика. Покрыты: двойная постановка до анимации, смена сбор→посев, самостоятельное новое нажатие, удержание клавиши и повтор после отпускания, сохранение и reload. Состояния сравниваются с обычными доменными операциями, включая прежние награды.

Полный набор этой ветки: 874/874, build/TypeScript/русский аудит проходят. Аудиокаталог подготовлен; оба аудита runtime/dist: 164 записи, 152 эффекта, максимум −6,34dB, missing/unreferenced пусты. Изменены только описания существующих событий сбора/посева, записи не генерировались.

## Проверка после правки

После согласованного освобождения renderer открыт новый отдельный профиль native Chromium с `--use-gl=angle --use-angle=swiftshader`, без изменения настроек безопасности и без unsafe/no-sandbox флагов. Использован тот же видимый post-rest стенд на localhost:5222; существующие сохранения не заменялись.

- Настоящий main, 390×844: книга яблочного тарта → раскрытие точного повтора → «Пшеница 0/1» снова выбрала зрелую морковь на второй грядке, отдельно объяснив сбор перед посевом.
- Тот же native double-click кнопки «Собрать +3» (два клика с удержанием по 60 мс) завершился только сбором. Сцена показывала «Вспаханная земля · Посеять: пшеница», пустую подготовленную грядку и три семени. Посев сам не начался.
- Только отдельный новый клик по «Посеять: пшеница» создал сухую пшеницу роста 0. Счётчик семян стал 2, действие сменилось на полив. Автополива не было.
- После настоящего Ctrl+R грядка и семена восстановились. В отдельном видимом читателе сохранения подтверждены валидный v3, день 4, монеты 25, работа 2, морковь 3, пшеница 0, семян пшеницы 2, вода 6, выбранная пшеница, рецепт s1 с одной приготовленной партией и одна готовая порция. Тыквы остались с ростом 0.
- Повтор Enter/Space и самостоятельное новое клавиатурное подтверждение проверены тестами, не объявляются отдельным native keyboard PASS.

В начале native-прохода некоторые bound-key команды не доставлялись. Стандартный `sky.press_key` и чтение следующего кадра позволили продолжить. Обхода браузерной защиты не было. После завершения окно закрыто кнопкой X; его отсутствие подтверждено свежим списком окон. Аппаратный FPS не измерялся.
