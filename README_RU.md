# Cozy Farm

Текущая браузерная игра находится в [папке game](game/README.md). [AGENTS.md](AGENTS.md) указывает действующие инструкции для реализации и проверки.

[Lavender Bay](01_primary_target/lavender-bay/01-master-island.png) задаёт действующий художественный стиль Cozy Farm. При работе с объектом сверяйте перспективу, масштаб, палитру и свет с текущей сценой по [руководству по ассетам](08_docs/ASSET_USAGE_GUIDE_RU.md). Готовую игру проверяйте по [чеклисту](08_docs/QA_CHECKLIST_RU.md).

Папки с досками, текстурами, старыми UI-листами, манифестами и скриптами нарезки хранят материалы исходного пакета. Актуальные задания для генерации находятся в [09_prompts](09_prompts/PRODUCTION_PROMPT_SEQUENCE_RU.md).
