# Cozy Farm

- Implement and verify the current game in `game/`. Use the scripts in `game/package.json`.
- **Audio.** For any added, changed or retired cue, take, prompt or trigger, follow [the sound catalogue workflow](game/audio-design/README.md). Update its bank and Russian event description in the same change, rebuild the catalogue and verify the actual gesture in the game.
- **Art, animation, palette, camera, or new assets.** Read [the Lavender Bay art workflow](08_docs/ASSET_USAGE_GUIDE_RU.md). Compare the running scene against the linked Lavender Bay masters at play scale.
- **Visual acceptance.** Use [the browser checks](08_docs/QA_CHECKLIST_RU.md). Review the assembled scene at play scale and exercise the affected interactions. Capture motion for animation, water, or physics changes.
- The old asset boards, manifests and slicers describe the historical reference package. For current generation, follow the art workflow and the user’s latest direction.
